更新日期：2026-10-05。本文汇总本地开发版的验证结果，不代表完整迁移、正式发布或所有游戏组合兼容。当前公开仓库提供说明文档，不提供这些开发产物的下载。

## 当前批次：登录反馈与恢复流程

工作区自动化检查为 **304 项通过、0 项失败、1 项忽略**，其中核心 211 项、桌面 93 项通过；全部目标的严格 Clippy 检查通过。构建前后核对的 138 份源码与资产输入保持一致。测试数量不是原版功能覆盖率。

本批补充了登录错误分类及恢复按钮、限定类型的一次重新认证、待执行操作的原账号绑定、披风暂选后确认、29 个原版披风中文名称，以及消息框和三色提示队列。测试覆盖过期与旧事件、取消、刷新失败、远端变更后不重复提交、披风点击不提交及取消草稿等行为。

## 登录服务的真实验证状态

自有应用已配置为支持个人 Microsoft 账号的公共客户端，真实设备码请求成功。随后一次真实尝试在 Minecraft Services 的 `login_with_xbox` 阶段返回 **HTTP 403**。

按照实现中的调用顺序，可以推断此前 Microsoft、Xbox Live 和 XSTS 阶段已完成；这不是各服务独立响应日志的验收。HTTP 403 说明请求被拒绝，但不足以单独确认原因是应用资格、配置还是其他访问限制。

Minecraft AppID 访问审核申请已提交，**尚未确认审核通过**。本批没有新增真实授权尝试。所有权、玩家资料、真实刷新凭据保存与恢复、续期和皮肤/披风变更仍未完成端到端验收。实现与恢复语义见[登录说明](login.md)。
