# 项目图标

`pcl-rust-icon-v2.png` 用于项目首页和应用图标，基于 Patrick 设计的原版 PCL 图标改编。

- **原图**：[上游 icon.ico](https://github.com/Meloong-Git/PCL/blob/0e0d12fdce6a2804916fb2be60e41144da637c18/Plain%20Craft%20Launcher%202/Images/icon.ico)。以原版图标的 PNG 转码作为生成参考；[应用图标](../../crates/pcl-desktop/assets/icon.png)现已替换为改编稿。
- **制作**：Codex 内置 `image_gen`，2026-10-05。
- **提示词摘要**：保留原版蓝色六边形轮廓与 PCL 字样，加入 RUST 字样，透明背景，作为第三方 Rust 版本的项目图标。

原版资产的许可与署名见[来源记录](../../crates/pcl-desktop/assets/upstream/README-SOURCES.md)和[上游许可](../../UPSTREAM-LICENCE)。此改编不表示原作者对本项目的背书。
