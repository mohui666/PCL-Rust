# 界面一致性复查（2026-10-05）

针对用户反馈的错位、无意义空白、列表裁切、下拉/输入及点击失效，按现有 Windows PCL 2.13.1.1 参考继续检查。登录协议与联机不在本轮范围；账号页只核对布局。检查采用逐文件静态核对及生产 egui 渲染器的几何/输入回归，不能等同于全页面 Windows 像素验收。

## 本轮发现与修复

- 静态标题文字默认可选，会抢走父行点击：限制到定位标签的子 UI，真实按钮和输入框仍使用自身交互。
- Minecraft 分类残留 300 DIP 内层滚动：交由页面滚动；空分类不显示；版本名及副行保持单行边界。
- 组件选中版本过长会进入清除按钮区域：加载器、OptiFine 与 API 卡头省略显示。
- 鼠标进入版本设置按钮或 Mod 开关时，父行失去 hover，子控件及背景不稳定：按整行包含鼠标判断，停留多帧仍能准确点击。
- 实例设置重复叠加默认行间距；内存单选同行高度不同；高级选项多出空标题块：使用显式行距、统一单选槽及同一折叠卡。
- 启动设置长皮肤文件名、Java 刷新按钮及自定义尺寸区挤出窄页：限制文字、固定操作宽度，并按分隔字形实际宽度分配尺寸输入。
- 长任务名挤出取消/重试或历史状态；嵌套步骤没有扣除缩进宽度：为操作/状态预留列，按实际右界截断步骤。
- 底部状态长文字覆盖取消/日志且挤出右界：先分配操作区，再约束文字，两个入口均验证可点击；有进度时限制操作行高度，保留进度轨道。
- 输入弹框长说明、Mod 更新长错误会被裁掉：说明区域可滚动，输入和底部操作仍保持可见。
- 启动按钮长版本副标题、披风长别名越界：前者按上游省略，后者限定整行点击与绘制范围并保留完整悬停文字。
- 自定义主页匿名下拉忽略初始 Text：首次显示配置值，后续用户选择不被每帧重置。

## 验证边界

长列表检查覆盖 120 条游戏版本的末项、40 个本地实例的末项与设置按钮，Mod 开关停留后实际切换隔离样本文件；长文本、最小窗口、输入焦点、键盘与鼠标目标均采用生产布局。全部测试使用隔离配置，不改用户游戏和账号。

原生检查仍停在上轮 Mac 锁屏拦截，等待手动解锁；本轮不新增新包截图、保存下载完成、启动就绪/关闭或 Windows GUI 的通过结论。最终统一测试、构建、CI 及包哈希见 [验证记录](validation.md)。
