## 本次截图暴露的漏项

此前实例设置页尾常驻的初始化/恢复/全局设置三个大按钮不符合原版布局，前轮静态走查漏掉了位置对照。原版 `PageInstanceLeft.xaml` 把初始化图标放在左侧“设置”行，`PageInstanceSetup.xaml` 页尾仅保留居中的全局设置箭头入口。恢复能力是本版保留的补充操作，应放在初始化图标的辅助菜单，不占据页尾。

截图中的高级选项大按钮来自尚未重启的旧进程；同时，当时新源码中的三个页尾大按钮也确实漏改。本轮已将初始化移回侧栏，恢复操作移入辅助菜单，页尾改为原版居中箭头按钮，并重建、重开 Mac 新包。原生确认弹框/取消、高级选项展开和全局设置跳转已检查；页尾几何位置通过 810/989 宽度布局检查。原生滚动工具仍报 noWindowsAvailable，尚未取得页尾原生截图，不把测试计为逐像素验收。
