## 帮助文档完整 XAML 格式

内置帮助保留固定上游原始 XAML，详情进入共用渲染器，不再把正文降成文本片段。已恢复 31 个内部帮助链接的标题、说明和图标，以及折叠箭头和标题字重；220/250 DIP 图片边距不再被 i8 截断为 127，正负边距均保留。编写规范中的一个上游失效示例引用显示未收录并禁用，不改指向其它内容。富文本 Run/Span/粗体/斜体/下划线、颜色/字号/行高/换行对齐、四边 Padding、同格 Grid 图文叠放、卡片/提示/图片及显式事件按当前支持范围处理；本地/远程帮助沿用同一安全边界。固定帮助正文的批量解析/渲染统一检查以最终验证记录为准；源码接入不等于每篇原生显示或逐像素验收，也不承诺任意 WPF 文档兼容。

## 原版范围的纠正

Forge universal/client ZIP 不再列为自动安装迁移缺口。固定上游 `Pages/PageDownload/PageDownloadInstall.xaml.vb:724、757` 明确“跳过无法自动安装的版本”，Rust 继续遵守该范围；本轮没有通过放宽校验或开发任意 ZIP 注入来冒充原版支持。真正补入的是原版已经处理的旧 installer/native 与 `map_to_resources` 路线。可信样本覆盖有限，不能推广为全部历史安装器或游戏适配。

原版同样拒绝真实 RAR 与目录拖入，不计为迁移缺口。列表拖拽排序和全局备份图形恢复选择器尚未确认属于原版对应能力；当前是否提供与是否漏迁需分开描述。
