## 九类能力

| 类别 | 当前功能 | 限制 |
| --- | --- | --- |
| 窗口尺寸 | 记住正常窗口宽高，重开恢复；退出补写，按屏幕限幅 | 不记忆窗口位置；最小化、最大化和全屏不覆盖普通尺寸 |
| 分页初始化 | 启动、个性化、其他、全部偏好分别初始化；先备份并检查配置是否被外部修改 | 分页保留其它页、目录、账号输入和提示状态；全部偏好会重置提示状态；暂无全局备份恢复界面 |
| 提示关闭记忆 | 保存高级启动、实例设置、主页风险及文档中可关闭提示的状态 | 不导入原版全部提示键和条件 |
| 页面动画 | 页面卡片、侧栏、标题和宽度使用原版时序与缓动；切换中阻止错位内容点击 | 不是通用 WPF 动画引擎 |
| Mod 信息 | 本地描述、作者、依赖和冲突；按校验哈希关联远端名称、译名、标签和图标 | 未识别文件不按名称匹配；未知版本或内嵌依赖标为不确定，不自动修改 Mod |
| 崩溃分析 | 解析 Fabric 建议、Forge MOD 失败块、Mixin、异常栈和 Mod 清单；提取实体/方块位置 | 区分日志明示错误与关联候选；不自动删除实体、修改存档或上传日志 |
| 主页 XAML | Style.BasedOn、文档内双向绑定、跨节点显示属性、Trigger、Hidden/Collapsed | 仅支持已列语法；不执行 CLR、转换器或自动副作用事件 |
| 任务进度 | 组件声明权重和依赖，实际阶段事件推进；基础安装权重为 5/14/4/14/1/1 | 权重不是字节比例或预计时间；未上报进度的工作只在完成时结算 |
| 历史安装 | 旧 minecraftforge 坐标、native 分类器、重复库校验；按实例目录补 map_to_resources | 官方 1.6.x 三款样本已验证库准备，未执行 Java/游戏；未知处理器、ZIP64/分卷/自解压仍受限 |

逐页代码位置和设置项见 [迁移矩阵](migration-matrix.md)。

## 三端启动器导出

导出页默认附带 Windows、macOS、Linux 启动器，可取消勾选。支持自动发现或手选 `launcher-bundle`；Mac 应用字体和签名资源完整保留，Linux 包包含 Noto Sans SC 与 OFL。缺少任一平台时明确报错。目录和构建步骤见[开发说明](development.md#导出时附带三端启动器)。本批测试 619 项通过、4 项忽略，平台构建与实际导出结果见[验证记录](validation.md)。

## 帮助和输入控件

内置帮助保留原始 XAML，支持富文本、字号/颜色/行高、四边 Padding、正负 Margin、Grid 图文和图片对齐。已恢复 31 个内部帮助链接的标题、说明和图标；上游缺失示例显示“帮助条目未收录”并禁用。

版本独立设置会重读当前实例配置，输入框文字垂直居中。最终 Mac 已检查帮助跳转、Forge 图文布局、独立设置往返和 CF 输入提示。30 篇帮助正文的两宽布局测试及具体结果见 [验证记录](validation.md)。

## 原版范围的纠正

固定上游 `Pages/PageDownload/PageDownloadInstall.xaml.vb:724、757` 跳过 universal/client ZIP 自动安装，Rust 沿用该范围。本次增加的是旧 installer/native 与 `map_to_resources` 路线，未增加 ZIP 注入。

原版也拒绝 RAR 和目录拖入。列表拖拽排序、全局备份恢复界面尚未确认属于原版能力。
