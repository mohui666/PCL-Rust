## 明确限制

| 范围 | 真实剩余边界 | 当前处理 |
| --- | --- | --- |
| 原版私有外观与内容 | 主题 1–13 私有精确参数、回声洞原始句库；用户截图未覆盖逐主题/全部状态 | 主题可用但明确是近似；默认蓝公式有公开依据。 |
| 通用 WPF/事件 | 任意 CLR/代码后置/对象构造、转换器/任意数据源、完整测量与动画、自动副作用事件；未知系统字体回退，NoWrap 为单行省略 | 已支持 BasedOn、局部双向/跨节点显示、状态 Trigger 与帮助富文本。未声明/前向静态资源不任意解析；未知协议报错；远程事件需点击。 |

## 正常的禁用状态

- 运行游戏、同目录写入冲突、未选目标、无合法版本或不兼容组合，会阻止提交或排队；写入任务结束后释放目录占用。
- 自动内存、跟随全局等模式下，对应手动字段不可编辑；缺合法可导出 Java 或字体分发受限时附带选项不可用。
- CurseForge 未配置有效 Key 或项目不允许 API 分发时明确失败，不静默改来源或假装数据为空。
- 正版 TLS 证书校验始终启用；账号端点不走下载镜像。
- 消息框入场短暂禁用指针、保存中的按钮锁定属于交互状态。

旧 PCL 配置导入、百宝箱、反馈、投票和离线赞助劝导已按用户要求排除，整合包导入和上游署名保留。历史产物与限定验证见 [验证记录](validation.md)，43 页/191 键完整对照见 [迁移对照表](migration-matrix.md)。
