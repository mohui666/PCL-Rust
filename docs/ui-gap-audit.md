# 非登录功能与 UI 缺口核对

日期：2026-10-05。外观基准为 Windows PCL 2.13.1.1 用户截图，行为与控件参数另对照官方固定源码提交 `0e0d12fdce6a2804916fb2be60e41144da637c18`；两者并非同一版本。本表按当前主工作区代码核对，记录本轮非登录功能的实际范围，不表示全量迁移、全部页面实机或逐像素验收。本表不重复填写本轮总测试数；统一检查和安装包结论以最终验证记录为准，不按测试数量推定功能覆盖率。

## 正常的禁用状态

- 安装/更新/导出期间的单写任务锁、未选目标、无合法版本或不兼容组合，会阻止提交；真实终态后释放。
- 自动内存、跟随全局等模式下，对应手动字段不可编辑；缺合法可导出 Java 或字体分发受限时附带选项不可用。
- CurseForge 未配置有效 Key 或项目不允许 API 分发时明确失败，不静默改来源或假装数据为空。
- 正版 TLS 证书校验始终启用；账号端点不走下载镜像。
- 消息框入场短暂禁用指针、保存中的按钮锁定属于交互状态。

旧 PCL 配置导入、百宝箱、反馈、投票和离线赞助劝导已按用户要求排除，不恢复为本次待办；整合包导入和上游署名保留。历史产物与限定验证见 [验证记录](validation.md)，43 页/191 键完整对照见 [迁移对照表](migration-matrix.md)。
