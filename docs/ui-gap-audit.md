## 本次补齐

本节对应当前工作区新增源码，不沿用此前 304 批安装包或公开副本的验收结论。共享下拉控件已按原版参数重做，并在最终 Mac 应用与隔离预览中检查。具体构建、测试和视觉范围见验证记录；不据此认定所有原版页面像素等价。

## 正常的禁用状态

- 游戏/安装任务进行中，修改实例文件、重复安装或导出受到锁定；结束后恢复。
- 未选目标实例、加载器或资源版本，输入不合法，或当前版本不支持该组件时，操作不可提交。
- 自动内存、跟随全局配置等模式下，对应手动字段不可编辑。
- mrpack 中游戏本体是必需项；当前仅 Modrinth 引用的来源选项是格式/实现约束，不是可切换的双源支持。
- 正版 TLS 证书验证始终启用。这是保留的数据保护规则，不是待补的“关闭验证”功能。
- 消息框入场短暂禁用指针提交、保存/授权进行中的按钮锁定属于交互状态。

旧 PCL 配置导入、百宝箱、反馈、投票和离线赞助劝导已按用户要求排除，不恢复为本次待办；整合包导入和上游署名仍保留。
