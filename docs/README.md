## 状态怎么读

| 用语 | 含义 |
| --- | --- |
| 已实现 | 当前源码中有可定位的实现；不单独表示真实服务或游戏通过。 |
| 局部实现 | 对应原版能力的一部分；表格同时列出已支持范围和限制。 |
| 已验证 | 有明确证据，须连同平台、构建与方式阅读：自动化、原生 UI、网络或游戏。 |
| 未验证 | 有实现或检查条件，但相应的实机/服务/组合尚未完成验证。 |
| 受限 / 未迁移 | 前者有明确格式、平台或来源限制；后者尚无对应实现。 |
| 本轮排除 | 用户明确不纳入当前工作，如登录和联机；不计作本轮通过。 |
| 待核实 | 当前事实仍在确认，不能当作成功或失败结论；登录审批以登录说明为准。 |
| 历史记录 | 只适用于所列提交/构建。保留供追溯，不自动覆盖新版本。 |

验证结果注明平台、提交和检查方法。构建、界面操作与游戏运行分别记录；历史结果仅适用于对应版本。
